# arXiv q-fin 研究雷达

对 arXiv（重点 q-fin.ST / q-fin.TR，兼顾 cs.LG / stat.ML 金融应用）做长期跟踪整理，筛选与「A 股因子实验室」架构产生理论交集的研究，沉淀为可执行的结构假设。

## 与我们系统的对应关系（评估锚点）

| 我们的模块 | 评估时问的交集问题 |
| --- | --- |
| 数据层（tushare→qlib，分钟/竞价自录） | 有没有更好的数据表示、聚合、微观结构信息利用方式 |
| 因子层（日频 + dragon 160 维分钟因子） | 因子构造是否可学习化、稀疏化、结构化（张量/图） |
| regime 门控（HMM） | 市场状态定义是否过时；记忆与重放；非平稳适应 |
| 模型层（ALSTM walk-forward） | 时序架构替代；非平稳下模型排序为何反转；验证纪律 |
| 信号层（top-10） | 排序学习目标、区分度、衰减、拥挤 |
| 模拟层（sim_v2，T+1 开盘价口径） | 成本/冲击/可执行性研究 |
| 进化闭环（胜率回灌） | **最重要**：如何防止进化循环 itself 成为假发现机器 |

## 文件结构

- `INDEX.md` — 长期主题索引（按研究线索聚合，跨期追踪）
- `digest_YYYY-MM.md` — 每期消化记录（当月新论文 × 交集评估 × 可尝试方向）

## 优先级约定

- **P0**：直接指向当前系统已知弱点，可立项验证
- **P1**：结构级启发，值得做小规模探针实验
- **P2**：背景认知，改变我们对问题的理解，暂不动手
