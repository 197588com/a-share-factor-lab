# 立项卡：A 股慢周期日历因子探针

- 提出日期：2026-11-14
- 来源线索：INDEX 线索 8（日历/季节性因子族）
- 文献锚点：Global Seasonality Factor Investing（arXiv 2611.15657,2026-11-11）
- 级别：P1 探针（低成本、单因子层、不进主模型）
- 状态：**待评审**

---

## 1. 假设（预先冻结）

- **H1（主假设）**：A 股存在可利用的**慢周期**日历效应——候选：月初/月末窗口、周几、春节/国庆节前 N 日、季末。预期方向：净收益为正且截面可区分。
- **H2（边界假设）**：快周期日历模式（需高频进出的）在 T+1 + 涨跌停约束下净收益为负，预期不通过；探针只验证慢周期。
- **H3（增量假设）**：日历因子与现有量价/动量因子族截面相关 |ρ| < 0.3，即构成独立收益源。

文献依据：2611.15657 跨债券/商品/股票期货验证五种季节异象，慢周期（季/半年/年）净收益为正、与传统 carry/动量/偏度因子不相关；快周期（周几、月内日）毛收益强但换手吃成负。A 股映射时预期只有慢周期可存活（T+1、涨跌停、集合竞价）。

## 2. 数据口径

- 数据源：现有 tushare → qlib 日频行情，**无需新数据源**。
- 样本：与现有因子池口径一致（全 A，剔除 ST、上市 < 1 年、停牌）。
- 区间：与 walk-forward fold 0–11 对齐；**holdout(2026-07-01 后)封存不碰**（holdout_guard 既有纪律）。
- 因子构造：哑变量族，参数集预先冻结——
  - 月初/月末：各取前/后 N ∈ {1, 3, 5} 个交易日；
  - 周几：周一至周五哑变量；
  - 节前：春节、国庆前 N ∈ {1, 3, 5} 个交易日；
  - 季末：季末前 N ∈ {3, 5} 个交易日。
  - 构造方式先线性（哑变量均值差/截面分组），非线性逐市场拟合留作通过后的二期项。
- 成本口径：净收益核算按 sim_v2 既有成本假设（T+1 开盘价口径）。

## 3. 验证设计

1. 单因子检验：分组收益、IC/ICIR、年化换手、净收益（扣费后）。
2. 相关性检验：与现有日频因子族的截面相关矩阵（验 H3）。
3. 分市值层稳健性：大/中/小票分层，检查异象是否集中于某层（2611.09286 的教训：异象可能在全样本口径下被大票稀释）。
4. 统计纪律（线索 1 强制）：
   - 本探针作为一条候选登记进 `candidate_ledger.py`，计入 signal 月预算；
   - 参数集（上文 N 的取值网格）**在跑数前冻结**,视为一次多重比较族，判决阈值按 Bonferroni 族内校正;
   - **一次性判决**：不过就归档为负结果，不调参重试。

## 4. 验收标准（评审时冻结）

- **通过**:H1 中至少一个慢周期因子满足——样本外(fold 8–11)ICIR 族内校正后显著、扣费净收益为正、与现有因子 |ρ| < 0.3;且分市值层不倒号。
- **失败**:全部归档为负结果写入 digest/ledger，不进入因子池，不迭代重试。
- 通过后的下一步才讨论:是否进因子池候选、是否做逐市场非线性拟合(2611.15657 的做法)。

## 5. 范围外（本期不做）

- 快周期/日内日历交易（H2 预期不可行，不投入）;
- 进入 ALSTM 主模型或 top-10 信号层;
- 组合层集成与权重倾斜。

## 6. 风险提示

- A 股日历效应文献存活率低，节前效应可能与流动性/避险情绪混杂，解释需谨慎；
- 多重比较是本项目最大假发现风险——哑变量 × 参数网格必须预先冻结并族内校正；
- 春节日期逐年漂移，哑变量构造按交易日历对齐，不按自然日。
